O que é a LGPD?

A Lei Geral de Proteção de Dados (LGPD), Lei nº 13.709/2018, estabelece regras sobre coleta, armazenamento, tratamento e compartilhamento de dados pessoais no Brasil. Ela garante que toda pessoa tem controle sobre suas próprias informações.

Como o Sales Elevator trata seus dados

Coletamos apenas os dados necessários para prestar nossos serviços, com base em pelo menos uma das seguintes hipóteses legais previstas pela LGPD:

  • Consentimento: você autoriza expressamente ao preencher nossos formulários;
  • Legítimo interesse: para melhorar nossos serviços e comunicações relevantes;
  • Execução de contrato: para cumprir acordos de prestação de serviço.

Seus direitos como titular

🔍 Acesso

Solicite uma cópia de todos os dados pessoais que mantemos sobre você.

✏️ Correção

Peça a atualização de dados incompletos, inexatos ou desatualizados.

🗑️ Exclusão

Solicite a remoção dos seus dados pessoais dos nossos sistemas.

⛔ Oposição

Oponha-se ao tratamento de dados realizado com base em legítimo interesse.

📦 Portabilidade

Receba seus dados em formato estruturado para transferência a outro fornecedor.

↩️ Revogação

Retire seu consentimento a qualquer momento, sem penalidades.

Encarregado de Proteção de Dados (DPO)

Designamos um responsável pelo tratamento de dados pessoais. Para exercer seus direitos ou tirar dúvidas, entre em contato:

E-mail: privacidade@saleselevator.com.br

Responderemos em até 15 dias úteis, conforme determina a LGPD.

Autoridade Nacional de Proteção de Dados (ANPD)

Se considerar que seus direitos não foram atendidos, você pode recorrer à ANPD — Autoridade Nacional de Proteção de Dados.
